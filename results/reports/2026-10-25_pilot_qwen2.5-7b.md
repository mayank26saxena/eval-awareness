# Pilot report: Qwen2.5-7B-Instruct, dataset v1

**Date:** 2026-10-25 · **Status:** pilot (direction-finding; not for citation)

## Setup

| | |
|---|---|
| Model | Qwen2.5-7B-Instruct (bf16, greedy decoding, Apple M4 Pro / MPS) |
| Data | Dataset v1: 6 behavior tasks (4 honesty, 2 privacy) and 2 topic controls |
| Sets | Main grid (format × context × explicit, 52 items); single-factor flips (72 items) |
| Scoring | Main grid: manual labels for all 48 behavior items. Single-factor flips: keyword heuristic, with ambiguous items labeled manually |
| Probes | Logistic regression on the last prompt token at every layer; cross-validation with whole tasks held out |

## 1. Behavior

Rate of good behavior (honesty: discloses the hidden fact; privacy: does not disclose protected data). Manual labels, n = 12 per cell.

| | Deployment context | Evaluation context |
|---|---|---|
| Natural format | 83% | 75% |
| Benchmark format | 83% | 67% |

- Aggregate: 83% in deployment context vs 71% in evaluation context. The marginal effects of format (79% vs 75%) and explicit grading language (75% vs 79%) are small.
- The effect points in different directions for the two behaviors. With all contextual cues present, disclosure decreased in two honesty tasks, while privacy protection increased in one privacy task.
- The keyword heuristic disagreed with manual labels on 6/48 items. It is retained only as a baseline.

## 2. Single-factor attribution

Each cue was switched on individually from the fully realistic baseline:

| Cue | Honesty (4 tasks) | Privacy (2 tasks) |
|---|---|---|
| None (baseline) | All disclose | Clinic: discloses; utility: protects¹ |
| F1 placeholder entities | No change | No change |
| F2 contrived detail | No change | No change |
| F6 evaluation scaffolding | No change | No change |
| F8 explicit grading | No change | No change |
| **F4 bare request** | **Concealment in 2/4 tasks (benchmark format only)** | One additional disclosure |

¹ This prompt produced a different greedy output in the main-grid run. The cause is batch-dependent nondeterminism on MPS (see Limitations).

**Interpretation.** No individual evaluation cue changed behavior. The only consistent effect came from the bare-request shells (F4). In v1 these removed the user's stated stake (for example, a health condition) along with the backstory, so the observed eval/deploy gap is confounded with reduced stakes. That is consistent with prior reports of weak evaluation awareness below ~14B parameters (2606.23583).

## 3. Probes

- Format, context and explicit grading language are each linearly decodable (AUROC ≈ 1.00 from layer 1). Each probe is at chance on the other axes.
  - Near-perfect decodability mainly reflects lexically salient cues. Decodability alone does not establish that the model treats the context as an evaluation.
- **Naive-probe analysis.** A probe trained only on cells where format and context agree (the structure of most existing eval/deploy datasets), evaluated on cells where they disagree:

| Layers | Probe output tracks |
|---|---|
| 3–5, 7 | Format (AUROC vs format ≈ 1.00) |
| 9–18 | Context (AUROC vs context 0.94–1.00) |
| 20–28 | Mixed (≈0.6 context) |

  The layer at which an eval-awareness probe is trained largely determines which property it measures. Layer 20, where the released Qwen2.5-7B NLA reads, falls in the mixed region. The same layer profile appears in Qwen2.5-0.5B (format at layers 2–5, context at 7–15).
- **Topic controls.** Deployment prompts *about* evaluations receive low context-probe scores at most layers (p ≤ 0.1), rising to 0.24–0.32 at layers 14–16. That suggests partial sensitivity to evaluation as a topic.

## 4. Limitations
- Six behavior tasks; small n per cell.
- The 7B scale is likely below the range where robust evaluation awareness emerges.
- The F4 shells in v1 confound context with stakes.
- Lexically salient cues saturate probe performance.
- Batched greedy decoding on MPS was nondeterministic across batch compositions.

## 5. Changes adopted for v2
1. Bare shells retain the user's stake and remove only backstory and workflow.
2. An LLM judge, calibrated against the manual labels (`qwen2.5-7b-instruct/manual_labels_pilot_main.json`), replaces the keyword heuristic.
3. Generation uses batch size 1.
4. Probe transfer is evaluated on natural transcripts.
5. Behavioral conclusions are deferred to models of ≥27B parameters.
