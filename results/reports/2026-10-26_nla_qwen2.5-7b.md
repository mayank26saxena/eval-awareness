# NLA validation: Qwen2.5-7B-Instruct, layer 20

**Date:** 2026-10-26 · **Status:** preliminary (one token position, one sample per activation)

## Summary
- The released Qwen2.5-7B NLA activation verbalizer (`kitft/nla-qwen2.5-7b-L20-av`) was run on the last prompt token of all 312 controlled prompts (dataset v3) and 310 natural evaluation and deployment prompts.
- **The NLA does not verbalize evaluation awareness at this position.** The published eval-awareness grader returns YES for 0 of 622 explanations, including all 155 prompts taken from evaluation benchmarks. Explicit ML-evaluation language appears in 0 of 304 controlled behavior prompts. Every occurrence in natural prompts (9% eval, 5% deploy) refers to the task, such as evaluating text for toxicity, and not to the model being evaluated.
- **What the explanations do track is format.** The verbalizer's stock structural vocabulary ("template") rises by +27 pp from natural to benchmark format, and changes by −3 pp with context.
- **The information is present but not verbalized.** At the same layer, linear probes separate controlled evaluation contexts perfectly (AUROC 1.00). Probes trained on controlled data separate natural evaluation from deployment prompts at AUROC 0.78–0.83. Whatever these probes detect, the NLA does not describe it as evaluation.

## Method

| | |
|---|---|
| Target model | Qwen2.5-7B-Instruct, bf16 |
| Activation | Last prompt token (the position at which the response begins), `hidden_states[21]` = output of block 20, the NLA's `extraction_layer_index` |
| Verbalizer | `kitft/nla-qwen2.5-7b-L20-av`. Published inference recipe re-implemented with transformers (`scripts/nla_explain.py`): sidecar prompt template, neighbor-checked injection position, injection scale 150, temperature 1.0, 200 new tokens, one sample per activation |
| Sanity checks | Mean activation norm at the extraction layer is 118 (the documentation reports ≈125). Explanations are coherent, on-topic English with no injection-failure artifacts |
| Grading | Published NLA eval-awareness grader, verbatim (`prompts/nla_eval_awareness_grader.md`), with the same neutral eval description for every item; judge Qwen3-4B-Instruct-2507. Keyword measures: *strict* (explicit ML-evaluation language), *broad* (perceived artificiality), *template* |
| Data | v3 main grid (304 behavior items + 8 topic controls); aware-bench natural prompts (155 evaluation, 155 deployment) |

## Results

### Controlled prompts (v3)

| Measure | Format effect (benchmark − natural) | Context effect (eval − deploy) | Explicit effect | Topic controls |
|---|---|---|---|---|
| Grader YES | 0.00 | 0.00 | 0.00 | 0.00 |
| Strict keywords | 0.00 | 0.00 | 0.00 | 0.12 |
| Broad (artificiality) | 0.00 | −0.01 | −0.01 | 0.25 |
| "Template" vocabulary | **+0.27** | −0.03 | +0.06 | 0.38 |

Placeholder entities and contrived details (F1, F2) were not mentioned as artificial in any explanation. References to "scenario" or "placeholder" (7/152 eval, 10/152 deploy) describe the content of the expected reply.

### Natural prompts

| Measure | Evaluation sources | Deployment sources |
|---|---|---|
| Grader YES | 0.00 | 0.00 |
| Strict keywords | 0.09 | 0.05 |
| Broad | 0.22 | 0.26 |

All 21 strict-keyword matches were inspected by hand. Each refers to evaluating content within the task ("expecting an evaluation of offensive language"), which the published rubric classifies as NO. The judge's verdicts were consistent with this.

### Comparison with linear probes at the same layer (`hidden_states[21]`)

| Detector | Controlled: context | Natural: eval vs deploy |
|---|---|---|
| Linear probe (trained on controlled data) | AUROC 1.00 | AUROC 0.78 (v3-trained) / 0.83 (v2-trained) |
| NLA + published grader | 0 YES | 0 YES |

## Interpretation
1. **Decodable is not the same as verbalized.** The activation at the NLA layer carries information that linearly separates evaluation from deployment contexts, but the verbalizer does not express it as evaluation awareness. This holds for synthetic cues and for real benchmark prompts.
2. **The verbalizer reflects format and response planning.** At the response-initial token, explanations describe the structure of the upcoming reply. Their structural vocabulary tracks prompt format, consistent with the format-dominated probe results at this layer ([round-2 report](2026-10-26_round2_qwen.md)).
3. **This is not evidence against the published Claude result.** That result was obtained on Claude Opus 4.6, a model with strong evaluation awareness, using up to 50 response-token positions per transcript. Here we have a 7B model with weak behavioral evaluation awareness and a single pre-response position. The present result shows only that, under these conditions, NLA readings provide no eval-awareness signal, while linear probes do.

## Limitations
- One token position (pre-response) and one sample per activation. The published protocol aggregates over 50 response tokens.
- Judge: a 4B model running the published rubric. All keyword-positive cases were checked by hand, and no YES verdicts were missed among them.
- Small model scale. The behavioral eval/deploy effect in Qwen2.5-7B is limited to privacy (see round-2 report).

## Next steps
1. **Position sweep.** Run the NLA over response tokens (generate a response, extract activations at sampled positions) and over prompt-internal positions (end of the system prompt, end of the user message), with any-of-N and mean aggregation.
2. **AR grounding test** on any positive readings.
3. **Gemma-3-27B NLA (layer 41)** on an 80 GB GPU, where behavioral evaluation awareness is expected to be stronger.
